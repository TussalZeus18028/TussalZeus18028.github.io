## 修复渲染系统：Mermaid + 矩阵公式 + 代码增强

### 根因分析
- **Mermaid 不渲染**：marked.js 把 ` ```mermaid ` 代码块解析为 `<pre><code class="language-mermaid">`，但 mermaid 库需要 `<pre class="mermaid">` 或 `<div class="mermaid">`
- **矩阵公式不渲染**：marked 在解析 `$$...$$` 块级公式时，会转义 LaTeX 中的 `\bmatrix`、`\cdots`、`\vdots`、`\ddots` 等反斜杠命令为 HTML 实体，导致 KaTeX 无法识别

### 解决方案
- **预处理机制**：在 `marked.parse()` 之前，先用正则提取 ` ```mermaid ` 代码块和 `$$...$$` 块级公式，用占位符 `%%MERMAID_n%%` / `%%MATH_n%%` 替换，解析完再还原
- **公式还原**：使用 `katex.renderToString()` 直接渲染 `$$` 块级公式，绕过 `renderMathInElement` 对已转义内容的处理
- **Mermaid 还原**：生成带切换功能的 `.mermaid-wrapper` 容器，内含渲染视图（`<pre class="mermaid">`）和源码视图（`<code class="language-mermaid">`）

### 新增功能
- **代码块复制按钮**：每个代码块右上角添加"复制"按钮，点击后复制代码文本并显示"已复制"反馈
- **语言标识**：代码块左上角显示编程语言名称（如 PYTHON、JAVASCRIPT、SQL）
- **Mermaid 视图切换**：Mermaid 图表上方有工具栏，可切换"渲染视图"和"代码视图"

### 修改文件

## 修复 Mermaid 渲染时序问题

### 根因
highlight.js 在 mermaid 初始化之前执行，将 mermaid 代码块中的内容用 `<span class="hljs-xxx">` 标签包裹。mermaid 的 `startOnLoad: true` 读取 `innerHTML` 时拿到的是被高亮标签污染的内容，导致解析失败。

### 修复方案
1. **改变执行顺序**：mermaid 初始化移到 highlight.js 之前
2. **手动渲染**：使用 `mermaid.initialize({startOnLoad: false})` + 手动 `mermaid.render()` 替代自动加载
3. **跳过污染**：highlight.js 使用 `pre:not(.mermaid) code` 选择器跳过 mermaid 代码块
4. **三个文件同步修复**：index.html、all-articles.html、manager.py
