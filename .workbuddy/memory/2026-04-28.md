## 第三次修复：彻底重写 Mermaid 渲染架构

### 根因
对比参考渲染器发现：博客弹窗用的是字符串拼接 + innerHTML 注入 `<pre class="mermaid">${code}</pre>`，而**原始 mermaid 代码直接嵌入 HTML 字符串时，特殊字符（`<`、`>`、`&`）会被浏览器 HTML 解析器吃掉或误转义**，导致 mermaid.render() 拿到残缺代码。

### 关键改动
1. **`restoreBlocks()` 改用 `<textarea>` 存储原始 mermaid 源码**：textarea 的 `.value` 不受 HTML 解析影响，保证代码完整性
2. **弹窗 script 改为从 `textarea.value` 读取源码**：不再依赖 DOM textContent
3. **取消 `<pre class="mermaid">` 中间层**：直接 `.mermaid-chart-view` div 里放渲染结果 SVG
4. **切换视图从「一个切换按钮」改为「📊 图表 / 📄 代码」双按钮**，与参考渲染器一致
5. **CSS 类名统一**：`.mermaid-rendered` → `.mermaid-chart-view`，`.mermaid-source` → `.mermaid-code-view`

### 修改文件
- `index.html`：`restoreBlocks()` + 弹窗 script + 弹窗 CSS
- `all-articles.html`：同步修复
- `manager.py`：`restoreBlocks()` + async script + CSS
